# AI-challenge, неделя 1

## ВНИМАНИЕ 

Все задания можно проверять на финальном коммите, но тогда форма будет включать в себя контент из будущих заданий.
В целом, как будто ничего страшного.

## Задание 1

Как проверить:

1. Открыть коммит 47934f252d41bf973dc39e15ddde9d0947d70564
2. Запустить приложение week1/src/main/java/com/tutorial/ai_challenge/AiChallengeApplication.java
3. Перейти на http://localhost:8080
4. Напечатать что-то в поле ввода и нажать "отправить"

## Задание 2

1. Открыть коммит dda8e101887f35deb6409e2bd38a71d16bfbc6cd
2. Запустить приложение week1/src/main/java/com/tutorial/ai_challenge/AiChallengeApplication.java
3. Перейти на http://localhost:8080/compare
4. Выставить параметры формы по своему усмотрению (промпт, ограничение длины ответа, stop sequence, почему-то тут уже есть thinking,
мб навайбкодило.)
5. Нажать "сравнить".

## Задание 3

1. Открыть коммит dda8e101887f35deb6409e2bd38a71d16bfbc6cd
2. Запустить приложение week1/src/main/java/com/tutorial/ai_challenge/AiChallengeApplication.java
3. Перейти на http://localhost:8080/compare
4. Задать системный промпт согласно пункту задачи, нажать "сравнить", смотреть в правый ответ. (В случае, если
этот пункт с просьбой модели самой написать себе промпт, то сделать 2 прохода - получить промпт в ответе и подставить его).
На демо промпты запрошены заранее, чтобы не удлинять видео.
